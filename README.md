A [make.fun](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca) bounty entry for **Two Lines to Your Past Self**: a program that writes exactly two lines to `/output/entry.txt` — line one warns the writer's past self about one specific moment, line two says in one sentence why that moment mattered and what changed because of it.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic: two runs produce byte-identical output.
